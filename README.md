# サイコロタイマー

ボードゲーム用の「サイコロ」と「手番のタイマー」を1つにしたページです。
スマホを卓に置いて、画面を押すとサイコロが振れます。タイマーを出せば、手番の時間も同じ画面で計れます。
人の名前は入れず、色で区別します。

**開くページ:** https://yucca-1122.github.io/dice-timer/

スマホのブラウザで開いて「ホーム画面に追加」すると、アプリのように全画面で使えます。

## 画面は3つ（設定で選べて、スマホごとに覚えます）
- **サイコロ** … 画面いっぱいにサイコロ（はじめはこれ・2個）
- **サイコロ＋タイマー** … 上にタイマー、下にサイコロ（横向きにすると、左にタイマー・右にサイコロ）
- **タイマー** … 数字を画面いっぱいに。画面のどこを押しても次の人へ（下のボタンの段は除く）

たとえば、卓の左のスマホは「サイコロ」、右のスマホは「サイコロ＋タイマー」にして使います。

## サイコロ
- 画面のどこを押しても、いつもの個数を全部振ります（ボタンとタイマーの欄は除く）
- いつもの個数は、左上の［−］［＋］で 1〜6 個から選びます
- 下の［1］〜［6］を押すと、その回だけその個数で振ります（例: いつもは2個、この番だけ4個）。次にふつうに押すと、いつもの個数に戻ります。「いつも」と書いてあるのが、いつもの個数のボタンです
- 押すと約0.5秒転がって、全部いっしょに止まります。止まった瞬間に「カタン」と鳴ります（転がっている間は鳴りません）
- 転がっている間に押しても、振り直しはしません
- 目は、ブラウザの暗号用の乱数で、偏りが出ない取り方で決めます

## タイマー（2種類）
### 手番（くり返し）
- 人数（1〜6人）と、1番から順に1人ずつの秒数（1〜999秒。はじめは20秒）を決めます
- タイマーの欄を押すとスタート。0秒になると、すぐ次の人の秒数で始まります（最後の人の次は1番。ずっとくり返し）
- 自分の番が早く終わったら、タイマーの欄を押すと、すぐ次の人へ（余った秒は使いません）
- 押しまちがえたら［1人戻す］、休むときは［一時停止］（止まっている間にタイマーの欄を押すと再開）
- ［1人戻す］［一時停止］は下の段の大きめのボタン。この段は、ボタンの横や間を押しても次の人へ進みません（一時停止のつもりで次へ進んでしまわないように）
- 何周目か、次は誰か（例「次 ● 青 20」。丸はその人の色）も小さく出ます
- ゲームの途中で人数や秒数を変えたら、次の手番から変わります

### 持ち時間（将棋式）
- 人数（2〜6人）と、1人ずつの持ち時間（1〜180分。はじめは10分）、秒読み（なし・10秒・30秒・60秒）を決めます
- 自分の番の間だけ、自分の持ち時間が減ります。押すと自分の時計が止まり、次の人の時計が動きます
- 持ち時間が0になったら、秒読みがあれば、それから毎手番その秒数で指します。秒読みも0になるか、秒読みなしで0になると「時間切れ」。音が鳴って時計が止まり、押すと次の人へ進みます（その人は以後ずっと「時間切れ」）
- ほかの人の残りも、次の人から順に小さく出ます

### 見た目と音
- 画面のふちの線が、今の人の色で、上の真ん中から時計回りに減っていきます
- 残り3秒（設定で5秒）から、線と数字が点滅して「ピッ」と鳴ります
- 残りが半分になると「ポーン」（短い秒数のときは鳴りません）
- スタートは「ポポポーン」、早く終わって押して次の人へ進んだときは「ピロン」（手番・持ち時間のどちらも）。［1人戻す］では鳴りません
- 0秒になって自動で次の人へ進む瞬間は「ピーーッ」（時間切れの合図）
- 持ち時間（将棋式）の時間切れは「ピピピッ」と鳴ります
- 音はすべてその場で作っています（音のファイルは使っていません）。最初に画面を押してから鳴るようになります

## 設定（右上のサイコロの絵）
画面のモード、音（全体・サイコロの音・半分の音）、マナーモードでも鳴らす（iPhone）、タイマーの種類、人数、1人ずつの秒数か分、人の色（色を押すと、ほかの人と重ならない色に変わります）、秒読み、残りのカウント（3秒・5秒）を変えられます。
［この設定で始める］と［最初から］で、タイマーは1番・スタート前に戻ります（ゲームの途中は、もう一度押して確かめます）。

## 気をつけること
- 画面が消えないようにしています（対応しているブラウザだけ）。消えてしまう端末では、自動ロックの設定に気をつけてください
- 「マナーモードでも鳴らす」をオンにすると、iPhone で消音にしていても鳴ります。ほかのアプリの音楽が止まることがあります
- 設定は、使っている端末のブラウザの中にだけ保存されます。どこにも送りません（外との通信はしていません）
- タイマーの進み具合は保存しません。ページを読み直すと、タイマーはスタート前に戻ります

## ファイル
- `dice-timer.html` … アプリ本体（1つのファイル。外から何も読み込みません）
- `index.html` … 公開用のページ（`python tools/build_pages.py` で `dice-timer.html` から作ります。本体を直したら作り直します）
- `manifest.webmanifest`・`assets/icons/` … ホーム画面に追加したときの名前とアイコン
- `tools/build_pages.py` … 公開用のページを作る道具
- `tools/make_icons.py` … 元の正方形の絵から、アイコン一式（iPhone・Android・タブ用）を作る道具
- `tools/test_engine.mjs` … タイマー・乱数・並べ方の試験（`node tools/test_engine.mjs`）
- `tools/test_ui.mjs` … 画面の試験と撮影（Microsoft Edge か Google Chrome を見えないまま動かします。`node tools/test_ui.mjs`）
